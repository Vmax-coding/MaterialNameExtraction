# 素材名称提取器

使用 React + Ant Design 的本地浏览器插件，适用于桌面版 Edge / Chrome。点击插件图标后，在独立标签页整理名称，切换到广告后台粘贴时不会关闭工作台。

## 下载安装（不需要编程环境）

1. 点击此仓库的 **Code → Download ZIP**，解压整个项目。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启「开发人员模式」，点击「加载解压缩的扩展」。
4. 选择项目里的 **dist 文件夹**（里面有 `manifest.json`），不要选择项目根目录。
5. 将插件固定到工具栏，点击图标打开工作台，再点击「选择文件夹」。

如果拿到的是 `MaterialNameExtraction-v1.2.0.zip` 安装包，直接解压并选择包含 `manifest.json` 的文件夹即可。无需执行 npm 命令，也不需要启动服务器。

- 导出 `.xlsx` 包含名称与备注的文字值；页面上的单元格格式和公式本身不导出。
- 这是插件内的本地网页电子表格组件。依赖全部打包，不加载微软在线 Excel、不需要登录或上传素材。

## 功能

- 选择文件夹及其子文件夹，或一次选择多个文件。
- 去掉尺寸标记及其后面的项目名、日期和扩展名，按完整名称去重。
- 根据第一个连接符前的语言前缀分类，显示各语言数量。
- 搜索名称、人员缩写，支持空格分隔多个关键词。
- 每行快速复制；勾选后批量复制；一键复制所有筛选结果。
- 分页显示，支持跨页勾选；筛选不会清除已选项，包含筛选外的选择时会提示。
- 显示合并的尺寸、源文件数，可查看原始文件相对路径。
- 名称列表保存在本机，刷新或重新打开继续使用，清空列表可移除保存记录。
- 支持追加导入或替换列表，不识别的尺寸保留原名并提示「待检查」。

## 提取规则

例如：

```text
葡萄牙语-冰块拆脚底螺丝_XYY_TSY-1x1_Screw_261104.mp4
葡萄牙语-冰块拆脚底螺丝_XYY_TSY-9x16_Screw_261104.mp4
葡萄牙语-冰块拆脚底螺丝_XYY_TSY-16x9_Screw_261104.mp4
```

合并为：

```text
葡萄牙语-冰块拆脚底螺丝_XYY_TSY
```

识别最后一个由 `-` 或 `_` 引入，后接 `_`、`-` 或名称结尾的尺寸标记：支持 `1x1`、`9X16`、`16×9`、`1080x1920`、`9:16` 等。完整保留尺寸前的内容，不依赖固定人员缩写或项目名。同名匹配区分大小写。未识别尺寸时只去掉扩展名，并标为「待检查」，不会猜测删除末尾内容。

支持 MP4、MOV、M4V、WEBM、AVI、MKV、MPG、MPEG、WMV、FLV 及常见图片格式；其他文件自动忽略。

语言按名称首个 `-`、`－`、`–`、`—` 或 `_` 前的内容分类，没有分隔符归为「未分类」。因此命名应继续保持「语言-素材描述_人员缩写-尺寸_项目_日期」形式。

## 隐私与使用说明

只访问用户主动选择的文件的名称和相对路径，不读取视频或图片内容，不上传素材，不请求网站访问权限，也不注入其他网页。全部依赖已打包到插件内，安装后可断网使用；网络连接由插件 CSP 禁止。保存的是名称记录，不是文件内容或文件夹授权。

文件移动、重命名或增删后需要重新选择文件夹。取消「追加到现有列表」可以用最新内容替换列表；追加模式不会自动移除旧名称。文件选择可能出现浏览器自带的“上传”字样，这是本地文件选择控件的默认文案，本工具没有上传接口。

## 本地开发

需要 Node.js 22 或更高版本及 Python 3（仅用于 ZIP 打包）。

```bash
npm ci
npm test
npm run dev
npm run package
```

`npm run dev` 用于本地网页预览。`npm run build` 生成插件目录 `dist/`；`npm run package` 同时生成 `artifacts/MaterialNameExtraction-v1.2.0.zip`。修改源码后必须重新构建，并在浏览器扩展管理页点击插件的「重新加载」。

提交中保留 `dist/`，方便直接安装。自动化工作流会在推送或拉取请求时运行提取规则测试、类型检查和构建，并提供安装包 artifact。
